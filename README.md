One commit message for a bug fix that made everything worse, entered in
make.fun's "Worst Fix Ever: Funniest Commit Message" bounty.

The program (`main.ts`) writes a single commit message — at most 100
characters — to `/output/entry.txt`. A judge model compares entries two at a
time and keeps the funnier one.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
